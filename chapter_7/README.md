# Chapter 7: Introduction to Django

Django is a **batteries-included web framework** designed for building full-stack applications quickly. Django is ideal for **applications with server-rendered HTML, authentication, admin dashboards, and a well-structured ORM**.


## Install dependencies

```commandline
poetry install
```

## Launch app

Run the following command to launch the To Do API:

```commandline
cd blogsite
poetry run python manage.py runserver
```

## Run tests

```commandline
poetry run pytest
```
